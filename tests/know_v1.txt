# Code - knowledge core tests (made-up words, so only reasoning can pass them)
# > what you say
# = text that must appear in the answer
# ! text that must NOT appear
# :reset forgets everything

# an empty mind meets a fact about things it doesn't know
> Cat has 4 legs.
= saved: cat has 4 legs
= want to know: what cat is, what leg is
> What is a cat?
= about cat: cat has 4 legs
= don't know: what cat is
> A cat is an animal.
= saved: cat is an animal
= learned: what cat is
! want to know: what cat is
> How many legs does a cat have?
= answer: 4

:reset
# is-a chains and inheritance
> A blick is a zorp.
= saved: blick is a zorp
= want to know: what zorp is
> Zorps can fly.
= saved: zorp can fly
> Can a blick fly?
= yes: blick can fly
= because: blick is a zorp; zorp can fly
> A zorp is a kind of wug.
= learned: what zorp is
> Wugs have 6 legs.
> How many legs does a blick have?
= answer: 6
= because: blick is a zorp; zorp is a wug; wug has 6 legs
> Is a blick a wug?
= yes: blick is a wug
> Does a blick have 6 legs?
= yes: blick has 6 legs
> Does a blick have 4 legs?
= no: blick has 6 legs

# the closest fact wins (an exception)
> Blicks cannot fly.
= saved: blick cannot fly
= exception: blick cannot fly, although zorp can fly
> Can a blick fly?
= no: blick cannot fly
= (told)
> Can a zorp fly?
= yes: zorp can fly

# honest "don't know", naming the missing fact
> Can a blick swim?
= don't know: blick can swim
= missing: whether blick can swim
= (or whether zorp can swim)
! yes
> Is a blick red?
= don't know: blick is red
> Can a dax fly?
= don't know: never heard of dax

# contradictions are noticed, corrections are accepted
> A zorp is red.
= saved: zorp is red
> A zorp is not red.
= conflict:
= kept the known one
> Is a zorp red?
= yes: zorp is red
> Actually, a zorp is not red.
= replaced: zorp is red -> zorp is not red
> Is a zorp red?
= no: zorp is not red
> Wugs have 8 legs.
= conflict: new "wug has 8 legs" vs known "wug has 6 legs"
> No, wugs have 8 legs.
= replaced: wug has 6 legs -> wug has 8 legs
> How many legs does a blick have?
= answer: 8

# describing and listing
> What is a blick?
= about blick:
= blick is a zorp
= blick cannot fly
= blick has 8 legs (from wug)
= blick is a wug
! blick can fly
> What does a blick have?
= list: 8 legs (from wug)
> What can a zorp do?
= list: fly
> What is a wug?
= kinds of it: zorp
= don't know: what wug is

# already known and things that follow
> A blick is a zorp.
= already known: blick is a zorp
> Blicks have legs.
= already known: blick has legs
= follows from: blick is a zorp; zorp is a wug; wug has 8 legs
! saved
> How many legs does a blick have?
= answer: 8
> A blick is a wug.
= already known: blick is a wug
= follows from: blick is a zorp; zorp is a wug
> Blicks have 2 legs.
= saved: blick has 2 legs
= exception: blick has 2 legs, although wug has 8 legs
> How many legs does a blick have?
= answer: 2
= (told)
> How many legs does a zorp have?
= answer: 8
